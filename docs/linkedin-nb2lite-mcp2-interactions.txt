What breaks when an MCP server from July meets September's dependencies?

I revisited the Nano Banana 2 Lite image server I first wired into Claude Code in July. It no longer ran on a fresh install, and nothing in the repo had changed.

google-genai 1.x now gets an HTTP 400 from Gemini's Interactions API: the legacy schema is gone. The MCP Python SDK 2.x renamed FastMCP to MCPServer. Both fixes were small, and the mocked unit tests passed straight through the break.

The same server now runs from Claude Code, Codex and Antigravity CLI, with a live verify skill that proves the real API path. The cover was generated by the server itself.
